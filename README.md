# Saladbowl

A self-hosted Fishbowl / salad bowl party game for a group playing in the same room, each on their own phone.

Rebuilt from scratch, using the game rules of [avimoondra/fishbowl](https://github.com/avimoondra/fishbowl) (MIT).

Work in progress. The design lives in `docs/superpowers/specs/`.
